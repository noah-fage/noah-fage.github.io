Projects

sigil

A real-time detection engine. It runs Sigma rules against live Windows Sysmon telemetry and correlates related events into scored alerts mapped to MITRE ATT&CK. Scored on public attack logs I didn't write, it went from 5 of 34 to 21 of 34 after I fixed two telemetry bugs, and false alarms on a normal day dropped from 12 to 2.

Sentinel

A SOC dashboard built with FastAPI and React. Logs go to the Claude API with schema-enforced JSON output, and it returns ATT&CK-mapped findings with cited evidence, a 0 to 100 risk score, and a short prediction of the attacker's next moves.
