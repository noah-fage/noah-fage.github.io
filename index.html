I'm a Computer Science student at McGill. I build detection tooling, run it against real attack simulations in a home lab, and write up what went wrong.

Read the write-up. The numbers, labels and scripts are in the repo.

Things that broke

  1. A dash where I expected nothing.

    My injection rule looked for an empty StartModule. Sysmon writes a single dash. The tests passed and the rule caught nothing against a real attack.

    post

  2. 0x1fffff is not 0x001fffff.

    The LSASS rule matched the access mask as text. The public samples write it zero padded, so it never fired on any of them.

    post

  3. UTF-16 in, nothing out.

    wevtutil exported UTF-16 and my replay path reads UTF-8, so the whole export parsed into nothing until I forced the encoding.

    post

  4. Windows was most of the false alarms.

    The Desktop Window Manager creating a thread in csrss.exe, which it does all day. I excluded that exact pair by full path, so a dwm.exe in any other folder still fires.

    post
