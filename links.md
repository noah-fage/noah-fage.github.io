# Links

A short list of tools, frameworks and practice sites from the work on this site.
Some I use for the work on this site and some I'm just getting into. I'll keep adding to it.

</div>

<h2 class="section-label">Detection engineering</h2>
<div class="link-grid">
  <a class="tile" href="https://github.com/SigmaHQ/sigma"><strong>SigmaHQ</strong><span>The open rule format and the shared rule repository Sigil's rules are written in.</span></a>
  <a class="tile" href="https://attack.mitre.org/"><strong>MITRE ATT&amp;CK</strong><span>The catalog of attacker techniques every alert gets mapped to.</span></a>
  <a class="tile" href="https://mitre-attack.github.io/attack-navigator/"><strong>ATT&amp;CK Navigator</strong><span>For drawing coverage layers over the matrix.</span></a>
  <a class="tile" href="https://atomicredteam.io/"><strong>Atomic Red Team</strong><span>Small, runnable attack tests for checking that a detection fires.</span></a>
  <a class="tile" href="https://learn.microsoft.com/en-us/sysinternals/downloads/sysmon"><strong>Sysmon</strong><span>Windows telemetry that Sigil reads.</span></a>
</div>
