# Links

A short list of tools, frameworks and practice sites from the work on this site.
Some I use for the work on this site and some I'm just getting into.

## Detection engineering

- [SigmaHQ](https://github.com/SigmaHQ/sigma). The open rule format and the
  shared rule repository Sigil's rules are written in.
- [MITRE ATT&CK](https://attack.mitre.org/). The catalog of attacker techniques
  every alert gets mapped to.
- [ATT&CK Navigator](https://mitre-attack.github.io/attack-navigator/). For
  drawing coverage layers over the matrix.
- [Atomic Red Team](https://atomicredteam.io/). Small, runnable attack tests for
  checking that a detection fires.
- [Sysmon](https://learn.microsoft.com/en-us/sysinternals/downloads/sysmon).
  Windows telemetry that Sigil reads.

## Forensics and CTF

- [picoCTF](https://picoctf.org/). Beginner-friendly CTF with a forensics
  category.
- [TryHackMe](https://tryhackme.com/). Guided rooms for learning security
  skills.
- [CyberDefenders](https://cyberdefenders.org/). Blue team and DFIR challenges.
- [CyberChef](https://gchq.github.io/CyberChef/). A browser tool for decoding
  and reversing data.
- [Timesketch](https://timesketch.org/). Open-source forensic timeline analysis.

## IoT and firmware

- [IoTGoat](https://github.com/OWASP/IoTGoat). OWASP's deliberately vulnerable
  IoT firmware, the target in my research.
- [QEMU](https://www.qemu.org/). The emulator the device runs in.
